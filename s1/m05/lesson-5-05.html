Five mixed reps, drawing on the whole week — naming tenses, translating, and unmasking the deponent in one place. Then build a form of your own.

✅ TRY IT · translate

✅ TRY IT · the deponent
With no agent named, mīrātur means…
✅ TRY IT · spot the imperfect
Which of these is the imperfect passive?
✅ TRY IT · translate
Translate: Arachnē ā deā movēbitur.

Write your own: make one Latin form meaning “the wool is being arranged” (use ōrdinō, 1st conj., with lāna as subject). Then reveal one correct version.

Lāna ōrdinābātur. — lāna (nom. sg. subject) + ōrdinābātur (1st conj. imperfect passive, “was being arranged”). If you wanted the plain present “is arranged,” write Lāna ōrdinātur — drop the -bā- tense-sign.
